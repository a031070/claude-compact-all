# compact-all

Мод для [Claude Code](https://claude.com/claude-code): сжимает все запущенные
сессии разом — **только по вашей команде**.

За день сессии разрастаются, и утром каждая открывается с огромным контекстом.
Перед окончанием работы введите `/compact-all` — и каждая сессия, в которой вы
работали, будет сжата так же, как это делает `/compact`.

[English version](README.md)

## Установка

В поле ввода терминальной сессии Claude Code:

```
/plugin install compact-all --marketplace a031070/claude-compact-all
```

Ответьте `y`, чтобы добавить маркетплейс, и выберите область **user** — тогда
мод загружается во всех сессиях.

Из shell:

```bash
claude plugin install compact-all --marketplace a031070/claude-compact-all
```

В десктопном приложении, где `/plugin` не работает: нажмите **+** рядом с полем
ввода, затем **Plugins**, **Add marketplace** с `a031070/claude-compact-all`,
затем **Add plugin**.

Уже открытые сессии подхватят мод после перезапуска.

## Использование

| Команда | Что делает |
| --- | --- |
| `/compact-all` | Просит каждую запущенную сессию, где вы работали, сжать себя. |
| `/compact-all <инструкции>` | То же, и передаёт текст в каждое сжатие, как `/compact <инструкции>`. |
| `/compact-all status` | Список известных сессий: папка, число ходов, размер контекста, итог последнего сжатия. |

Каждая сессия сжимается **после того, как закончит текущий ход**, — начатая
работа не прерывается. Сессия, где введена команда, сжимается тоже.

Пропускаются:

- сессии, где за последние 24 часа не было ни одного вашего хода (окно
  активности, см. [Настройки](#настройки));
- сессии, в которых вы не отправили ни одного сообщения;
- сессии с контекстом меньше 100 000 токенов (параметр `minTokens`);
- незапущенные сессии: до закрытой сессии не достучаться, и отчёт об этом скажет.

## Настройки

| Параметр | По умолчанию | Смысл |
| --- | --- | --- |
| `activeHours` | `24` | Сжимаются только сессии, где последний ответ на ваше сообщение был не раньше, чем столько часов назад. |
| `minTokens` | `100000` | Сессии с меньшим контекстом пропускаются. |

Меняются в настройках плагина: `/plugin` в терминальной сессии, затем
**compact-all**. После изменения мод перезагружается с новыми значениями.

## Как устроено

- При старте каждая сессия с модом записывает в хранилище мода свою запись
  (id, папка, число ходов, токены контекста, время последнего хода) под
  собственным ключом. Запись удаляется при завершении сессии; записи, не обновлявшиеся 7 дней, отбрасываются.
- `/compact-all` читает эти записи и отправляет подходящим сессиям служебное
  сообщение через `$.session.send`.
- Мод в сессии-получателе перехватывает сообщение до модели, ждёт, пока сессия
  освободится, и вызывает `$.session.compact()` — тот же вызов, что и `/compact`.
  Итог показывается всплывающим сообщением и в `/compact-all status`.

Мод не читает файлы проекта и не запускает команд shell.

## Разработка

```bash
claude plugin validate .
claude plugin test .
```

Запуск из этой папки без установки:

```bash
claude --plugin-dir .
```

Мод использует API hooks-модулей Claude Code; он в раннем доступе и может
меняться между версиями.
